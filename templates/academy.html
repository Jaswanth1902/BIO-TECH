🧮 Mathematical & Predictive Intelligence Core

Adaptive Shelf-Life Model (Linear Regression)

Our predictive AI module uses a multivariate Linear Regression model to estimate remaining shelf life. The model uses features representing cumulative stressors:

Remaining Days = β₀ - (β₁ × T_avg) - (β₂ × T_max) - (β₃ × Hum_avg) - Elapsed Days
  • β₀ (Base Shelf-life): Initial shelf life allocation (60 days for medical/cryo, 30 days for foods).
  • Temperature Stressors (β₁, β₂): Penalizes exposure above safe biological baselines.
  • Relative Humidity Stressors (β₃): Evaluated dynamically for herbs (preventing volatile terpene oil degradation).
  • Elapsed Days: Time elapsed since the batch was registered at origin.
RAG Expert Search (Vector Cosine Similarity)

Preservation advice and chatbot queries are resolved via Retrieval-Augmented Generation (RAG) using the SentenceTransformer all-MiniLM-L6-v2 model:

cos(θ) = ( A · B ) / ( ||A|| × ||B|| )
  • Vector Embedding Conversion: Natural language queries and knowledge entries are mapped to 384-dimensional dense vectors.
  • Cosine Similarity Value (cos(θ)): Ranges from `-1.0` to `1.0` (where values `> 0.15` indicate high semantic relationship).
  • Instant Retrieval: The system matches the prompt with the most relevant scientific preservation standard, returning immediate, clinical advice.
